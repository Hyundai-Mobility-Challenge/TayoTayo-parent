# 학부모 앱 하원 시연 검토

검토일: 2026-11-14 (한국 시간). 변경 범위는 학부모 앱 저장소만이다. 서버 코드는 읽기만 했으며 수정하지 않았다.

## 이번 변경

- 서버의 인계 기록과 하차 기록을 구분한다. 인계만 기록되면 하차 대기를 안내하며 방문 완료로 표시하지 않는다.
- 서버에서 하차 또는 운행 종료를 확인하면 앱 화면의 실시간 위치와 ETA를 제거한다.
- 오늘 운행 조회 및 알림 대상 운행 조회에서 하차/운행 종료를 확인하면 이 앱이 저장한 해당 아이·운행의 공유 링크를 폐기한다.
- 중복 생성한 공유 링크 ID를 모두 저장한다. 기존 버전의 단일 링크 ID도 함께 처리한다.
- 폐기 성공한 링크만 저장 목록에서 제거한다. 이미 폐기된 링크(404)는 완료로 처리하고, 통신/권한 오류는 ID를 유지하여 다음 조회에서 재시도한다.
- 하차 후 폐기 실패도 홈에 표시하며 수동 종료 버튼을 유지한다.
- 공유 생성 직전에 서버에서 해당 운행을 다시 조회하고, 운행 중이며 아직 인계·하차되지 않은 아이만 공유한다.

이는 앱이 실행되어 해당 운행을 조회하는 동안의 보완이다. 앱 종료/오프라인 상태에서 즉시 폐기하거나, 다른 기기가 생성한 공유까지 종료하는 서버 정책을 대신하지 않는다. 다음 날 다른 운행으로 바뀐 경우 이전 운행은 해당 알림 등으로 다시 조회해야 이 앱의 정리 작업이 수행된다.

## 검증

- Kotlin 2.0.0 컴파일러와 캐시된 실제 의존성으로 비 Android 소스 및 JUnit 테스트를 직접 컴파일하고 실행했다.
- JourneyDataTest 13개 + ApiJsonTest 3개 + JourneySharesTest 9개: **25개 통과**.
- 추가 검증: 여러 링크 폐기, 인계/하차 분리, 부분 실패 후 재시도, 이미 폐기된 링크, 권한 오류 유지, 운행 종료, 공유 생성 전 상태 검사, 아이/운행별 분리, 하차 후 위치 제거.
- UI 회귀 테스트 2개 추가: 인계 후 하차 대기, 하차 후 공유 폐기 실패와 수동 재시도. **실행하지 못했다.**
- `git diff --check` 통과.
- Gradle `:parent:testDebugUnitTest :parent:assembleDebug --offline --no-daemon`은 Gradle daemon의 로컬 소켓 연결 제한으로 실패했다. APK 빌드 성공으로 간주하지 않는다.
- ADB는 daemon 시작에 실패했으며, 로컬 서버 `/health/database`도 소켓 접근 제한으로 접속하지 못했다. 이번 변경의 실서버·에뮬레이터·실제 휴대폰 테스트는 미완료다.

## 서버 변경 없이 해결할 수 없는 시연 항목

| 장면 | 현재 서버 근거 | 앱에서의 처리/한계 |
| --- | --- | --- |
| 전체 정류장 순서·방문 상태·실제 버스 진행 | GuardianTripController.today/detail은 내 아이 정류장만 반환한다. 차량 전용 운행 조회는 차량 credential이 필요하며 다른 아이 정보도 포함한다. | 보호자 앱에서 차량 권한을 사용하거나 경로를 추정하지 않는다. 내 아이 정류장만 표시한다. |
| 출발 푸시 | TripController.start는 운행 상태 변경만 하며 출발 알림 발송 호출이 없다. | 도착/하차와 동일하게 실제 출발 푸시를 받을 수 있다고 보장할 수 없다. 앱 조회는 기존 5초 주기를 유지한다. |
| 앱 종료 중 하차 즉시 공유 종료 | ShareAndCallController.getShare는 유효기간/폐기 여부를 확인하지만 하차 상태로 접근을 차단하지 않는다. TripController 하차 처리에도 공유 폐기가 없다. | 앱이 하차 정보를 조회하면 저장된 링크를 폐기한다. 앱이 꺼져 있으면 즉시 종료를 보장할 수 없다. |
| 실제 휴대폰 FCM | 앱에 수신/알림 대상 이동 처리는 있으나 서버 발송 및 기기 연결이 필요하다. | 이번 환경에서는 실제 수신을 검증하지 못했다. |

전체 시나리오가 구현·통합 검증되었다고 판단하지 않는다. 서버 수정 금지 조건하에서는 위 서버 의존 항목을 제외한 범위로 시연해야 한다. 모의 체험, 가짜 정류장, ETA만으로 도착·하차를 확정하는 로직은 추가하지 않았다.
